Conformal Prediction：从校准集到预测区间

A Gentle Introduction to Conformal Prediction and Distribution-Free Uncertainty Quantification

Anastasios N. Angelopoulos · Stephen Bates · 2022-12-08 · arXiv:2107.07511v6

Distribution-freeNon-asymptotic guaranteeCalibration setPrediction sets / intervalsSplit conformal
先记住一句话：Conformal prediction 不负责把模型预测变准；它拿一批没有参与模型训练的数据，估计“模型通常会错多远”，再把这个误差阈值加到新样本上，从而给出有覆盖率保证的集合或区间。

【来源：pp.4–6，Theorem 1】

这篇文章的证据类型

这是教程型综述，不是一项单一实验。它用分类、回归、异常检测、分布漂移和完整 conformal 的例子解释统一框架。

核心 01 · Calibration set

它不是用来训练模型，而是用来测量模型的非一致性分数，并选择 q-hat。

核心 02 · Prediction interval

回归中它是一个区间；分类中它是一个标签集合。区间会随输入难度自适应变宽或变窄。

核心 03 · Coverage

它说的是长期频率意义上的“真值落进集合的比例”，默认是 marginal coverage，不是每个子群都保证。

最容易犯的错误

把 final-heldout 当成调参集，或者在看过 final-heldout 标签后反复改 score、alpha、模型，再报告同一个 coverage。

阅读建议

先读四个概念和数据切分，再读 split conformal 的算法；最后看 coverage 的边界与 calibration size。

3 分钟讲清论文

问题：模型通常只给一个点预测或一个启发式置信度，但高风险场景需要知道“答案可能在哪里”。
办法：留出 calibration set，计算真实标签对应的错误分数，取一个高分位数 q-hat，再把 q-hat 用到新输入。
结果：只要校准样本和未来测试点可交换，覆盖率有有限样本保证，不需要假设数据服从高斯分布，也不要求模型正确。
代价：保证是 marginal 的；分数设计不好时，集合可能很宽或缺乏适应性。

最简摘要

Conformal prediction 是一个包裹层：它不改变底层模型，而用独立校准数据把启发式不确定性变成分布无关的预测集合。算法的核心是计算 calibration scores、取有限样本修正的分位数、再用该分位数构造新样本的集合或区间。

02

四个核心概念：你现在最需要理解的

1. Calibration set 是什么？

一批模型训练完成后才拿出来的数据，每个样本都有 x 和真实 y。它的任务不是更新模型参数，而是把模型的错误程度变成一个可校准的经验分布。

一句话：校准集是“用来量尺”的数据。

【来源：p.4–5，p.14】

2. Prediction interval 是什么？

在连续回归里，给定新输入 x，输出一个区间 [lower(x), upper(x)]，希望未来真值 Y 落入其中。它不是参数的置信区间，也不是“模型参数有 90% 概率在区间内”。

一句话：预测区间回答“下一个真实结果可能在哪儿”。

【来源：pp.8–10】

3. Coverage 是什么？

Coverage 是事件 Y-test ∈ C(X-test) 发生的概率。目标是至少 1−α，例如 α=.1 时至少 90%。论文默认保证的是 marginal coverage：平均跨过校准集和测试点的随机性。

一句话：长期重复使用时，真值有多大比例被罩住。

【来源：Eq. (1)，Theorem 1，pp.4–6】

4. 为什么区间会变宽？

如果底层模型认为某个 x 很难，score 或 uncertainty scalar 会大，区间自然会更宽；容易样本则更窄。这是 adaptivity 的目标，但 coverage 保证本身不保证这种适应性一定好。

一句话：覆盖率是可靠性，区间宽度是效率，两者要一起检查。

【来源：pp.5–6、12–14】

不要混淆：prediction interval 不是 confidence interval。confidence interval 讨论未知参数；prediction interval 讨论未来观测值。Conformal prediction 这里给的是未来真值的覆盖保证。
03

数据切分：训练、校准、最终评估各做什么

最稳妥的理解是：模型学习、阈值选择、最终报告分别需要不同的信息边界。

Train / fit

用来拟合底层模型 f-hat，例如神经网络、随机森林或 quantile regression。模型可以在这里学习参数。

→

Calibration set

冻结模型后，只计算 score s(x,y)，然后选择 q-hat。它是“校准阈值”的数据，不继续训练底层模型。

→

Final-heldout / test

在模型、score、alpha 和校准流程都冻结后，用来做一次最终评估。它的标签不能反过来参与设计。

数据可以做什么不能做什么如果越界会怎样
Train拟合模型、学习参数、训练 quantile regression。不能替代 calibration set 去选择 q-hat。模型误差被低估，校准不再是对未见数据的诚实测量。
Calibration计算分数、取 q-hat、在预先规定的候选程序中做校准。不应在每次看结果后随意改模型和 score。算法的“模型已固定”条件被破坏；需要新的独立校准。
Final-heldout一次性评估最终 coverage、平均区间宽度、子群表现。不能用来反复选 alpha、score、模型、分割比例或报告窗口。测试集被“训练”成设计集，最终 coverage 变成乐观且不可审计。
04

Split conformal prediction：完整构造过程

这是论文第 4–6 页给出的最常用版本。它只需要底层模型拟合一次，再用一批独立 calibration points 做校准。

Step 1 · 拟合底层模型

在 train set 上训练 f-hat。它可以输出分类 softmax、回归点预测、上下分位数或 uncertainty scalar。

Step 2 · 规定 score

定义 s(x,y)，而且分数越大表示“x 和 y 越不一致”。score 是最重要的工程选择。

Step 3 · 计算校准分数

对 calibration pairs (X-i,Y-i) 计算 s-i=s(X-i,Y-i)。注意这里使用了真实标签 Y-i。

Step 4 · 取有限样本分位数

q-hat 是 s-1,...,s-n 的 ceil((n+1)(1-alpha))/n 分位数，常用 higher quantile。

Step 5 · 部署新输入

新样本只有 X-test，没有 Y-test。把所有满足 s(X-test,y)≤q-hat 的候选 y 放进 C(X-test)。

Step 6 · 得到覆盖保证

若 calibration points 和 test point i.i.d.，则 P(Y-test∈C(X-test))≥1-alpha。【来源：Theorem 1】

q-hat = Quantile{ s(X-1,Y-1), ..., s(X-n,Y-n); ceil((n+1)(1-alpha))/n }
C(X-test) = { y : s(X-test,y) ≤ q-hat }
score 不是区间

它是一个对 (x,y) 的分数，必须结合 q-hat 和新输入才能形成集合。

q-hat 是全局阈值

普通 split conformal 用同一个校准分位数；输入相关的宽度来自 score 结构。

保证来自可交换性

不是来自模型正确，也不是来自高斯分布假设，而是 calibration/test 的交换性。

05

Prediction interval：回归里怎样构造区间

论文给出三种有代表性的回归分数。你当前最需要掌握的是 conformalized quantile regression，也就是 CQR。

方法 A · Conformalized Quantile Regression (CQR)

底层模型输出两个条件分位数：t-hat-alpha/2(x) 和 t-hat-1-alpha/2(x)。先定义校准分数：

s(x,y) = max{ t-hat-alpha/2(x) − y, y − t-hat-1-alpha/2(x) }

它衡量 y 跑到原始分位数区间外面多远；落在区间内时分数不为正。校准后输出：

C(x) = [ t-hat-alpha/2(x) − q-hat, t-hat-1-alpha/2(x) + q-hat ]

直觉底层 quantile regression 先给一个“有根据的初始区间”，conformal 再用 q-hat 统一向外扩张，补上模型分位数估计不足的部分。【来源：pp.8–9，Eq. (4)】

方法 B · uncertainty scalar

如果模型给点预测 f-hat(x) 和 uncertainty scalar u(x)，使用 s(x,y)=|y−f-hat(x)|/u(x)，最后构造 [f-hat(x)−q-hat u(x), f-hat(x)+q-hat u(x)]。【来源：pp.9–10，Eq. (5)】

这里 u(x) 可以是预测标准差、ensemble 方差、dropout 方差或残差模型。它提供自适应宽度，但不一定随 alpha 正确缩放。

一个数字例子：假设底层模型给出 [8,12]，校准集得到 q-hat=1.5，那么 conformalized interval 是 [6.5,13.5]。如果新样本真实值 y=13.1，它被覆盖；如果 y=15，它没有被覆盖。coverage 不是说这一个样本有 90% 概率，而是很多可交换样本长期重复时的频率保证。
06

为什么不能用 final-heldout 调参

这是你特别关心的重点。论文的核心定理并没有把“final-heldout 调参”作为一个单独标题展开；下面前半部分是论文直接给出的 validity 条件，后半部分是从该条件推导出的实验设计规则。

论文直接支持的部分

论文先要求模型已拟合，再用 fresh calibration data 计算 score 和 q-hat，最后对 fresh test point 给出 coverage 保证。【来源：pp.4–6】这意味着用于校准的规则必须在测试点到来前固定，测试标签不能参与 q-hat 或模型设计。

由此推导的实践规则

如果你用 final-heldout 标签比较多个 score、多个 alpha、多个模型或多个 calibration size，然后挑一个看起来最好的，再用同一批数据报告 coverage，那么这批数据已经参与选择。它不再是“未见的最终检验”，报告的 coverage 失去原本的确认意义。

行为是否可以正确做法原因
在 train 上训练 f-hat可以固定模型后进入校准。训练和校准的角色不同。
在 calibration 上选择 q-hat必须只用预先固定的 score 和 alpha。q-hat 本来就由 calibration set 产生。
在 calibration 上比较少量预注册候选可以，但要承认它是选择集选择后最好用新的 calibration 或 nested calibration 重新校准。候选选择消耗了 calibration 信息。
看 final-heldout coverage 后改 score不可以冻结方案后只评估一次；若改了，重新留出新的 final-heldout。否则最终评估集被反馈进设计环。
看 final-heldout 只做一次 sanity check可以把它作为最终报告，不根据结果再迭代。保持测试集的独立性。
关键句：final-heldout 不是“更高级的 calibration set”。它是你在方案冻结后，才允许回答“这套方案在未见数据上的 coverage 如何”的证据。
07

Coverage：保证到底覆盖什么

Coverage 是 conformal 最容易被过度解读的词。论文把 marginal、conditional 和 adaptivity 分得很清楚。

Marginal论文定理保证的默认对象对校准集和测试点的随机性平均，P(Y∈C(X))≥1−alpha。
Conditional更强，但一般不可能要求每个 x 或每个子群都至少 1−alpha；任意连续分布下通常无法同时保证。
Adaptive实践中要检查容易输入给小集合，困难输入给大集合；coverage 本身不保证这一点。

Marginal coverage 的例子

如果 alpha=.1，系统在大量可交换测试点上平均覆盖 90%。它可能在简单组覆盖 99%，在困难组覆盖 81%，平均仍可能接近 90%。这在统计上满足 marginal，但在应用上可能不公平。

为什么要看子群

论文第 13–14 页建议按 feature 或 set size 分层检查 coverage。若医疗场景中某个群体长期低于目标，单看总体 coverage 会掩盖风险。

Coverage 和宽度要一起报告：一个方法可以靠输出极宽区间轻松覆盖，另一个方法区间很窄但漏得更多。论文把 set size / interval width 和 adaptivity 作为重要诊断，而不是只看一个 coverage 数字。【来源：pp.12–15】

作者的统一视角

原文证据文章把 conformal prediction 描述为：将任意模型的 heuristic uncertainty 转成 rigorous uncertainty。模型可以是错误的，但 score 需要合理排序难易程度，才能让集合既有效又有用。【来源：pp.5–6】

解释coverage 是“安全底线”；score 决定“这条底线下是否浪费太多空间”。

Calibration set size · 第 14–16 页

覆盖保证对任意 n 成立，但固定校准集下的实际 coverage 会随机波动。论文用 Beta 分布分析这种波动，并给出 n=1000 时通常在 0.88–0.92 附近的直觉示例；这不是所有任务的普遍数值承诺。【来源：pp.14–15、Appendix C】

Split vs full conformal · 第 27–28 页

split conformal 只拟合一次模型，再用独立 calibration set；full conformal 允许模型在所有数据上拟合，但对每个候选标签/响应都要重新计算，计算成本更高。split 牺牲一些统计效率换取简单和速度。【来源：pp.27–28】

局限性与批判性评价

  1. Coverage 是 marginal 的。不能自动推出每个群体、每个 x 或每种难度都达到目标。
  2. 有效不等于高效。score 如果很差，集合可能大到失去决策价值；需要报告平均宽度和 adaptivity。
  3. i.i.d. / exchangeability 是边界。covariate shift、时间漂移、相关数据需要加权、滑动窗口或专门扩展。
  4. 小 calibration set 会造成波动。定理仍成立，但某一个固定 calibration set 的实际 coverage 可能偏离目标。
  5. 调参会消耗独立性。只要 final-heldout 结果被拿来挑方案，它就不再是最终验证集。
  6. “90% coverage”不是概率陈述。在给定 x 后，不应解释为真值有 90% 概率在这个具体区间内；这是重复抽样下的频率保证。
综合评价：较强的入门教程。它把统一算法骨架、实用例子和理论边界放在一起；学习时要把作者给出的 coverage 定理，与模型质量、区间窄度、conditional coverage 和真实部署分开。

导师汇报版与答辩问题

60 秒汇报：Conformal prediction 是一个模型无关的校准层。先在 train set 拟合任意模型，再在 calibration set 计算真实标签对应的 nonconformity scores 并取有限样本修正分位数 q-hat，最后对新输入输出 score 不超过 q-hat 的集合。若 calibration 与 test 可交换，则真值的 marginal coverage 至少是 1−alpha。它不保证模型正确、区间很窄或每个子群都覆盖；final-heldout 必须在所有选择冻结后才能使用。
答辩：为什么 calibration set 不能继续训练模型？

因为它需要提供模型在未参与拟合的数据上的真实误差分布。若模型在这些点上继续更新，score 会被人为压低，q-hat 失去“未见误差”的含义。实践上可以做交叉 conformal 等更高效方案，但必须重新分析流程。

答辩：coverage 90% 是不是当前区间有 90% 概率包含 y？

不是这种单次后验概率解释。标准 split conformal 给的是对随机校准集与随机测试点平均的 marginal coverage 频率保证；给定一个已经固定的 x 和区间，不能直接把它解释成 90% 的概率声明。

答辩：如果我看了 final-heldout，发现 coverage 只有 84%，怎么办？

先把这次结果当成诊断，检查实现、数据交换性和样本量。若要改 score、模型、alpha 或切分，必须承认 final-heldout 已被使用，并重新留出一批新的最终测试数据；不能继续把原数据称为 untouched test。

答辩：split conformal 的一句话算法是什么？

固定底层模型，计算 calibration scores，取 q-hat，然后把所有新候选 y 中 score 不超过 q-hat 的放进 prediction set；回归时通常表现为在原始区间两端各扩张 q-hat。
